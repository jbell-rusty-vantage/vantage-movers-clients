## Presentation and shared behavior

`apps/main-site/src/lib/presentation.ts` selects the presentation. Semantic palette, spacing, shapes and component hooks live in `styles/presentation.css` and the three `canyon-*.css` files. The home composition selects the Canyon section order while retaining the five-step planning interaction, interactive map, quote placements and all baseline content. Shared editorial templates extend the design to the other pages and Spanish. The actual site logo and existing CMS imagery replace the artboard's placeholders.

The default Turbopack build selects the font module from that same preset in `next.config.ts`. Both presets use licensed local WOFF2s. Canyon preloads only Inter and Plus Jakarta Sans (271,776 bytes); the first implementation unnecessarily preloaded seven faces (1,974,472 bytes). Both presets passed production-mode builds with the correct English and Spanish preload manifests. Font sources, conversion notes and checksums are in `src/fonts/webfonts.json`. The immersive home image requests `100vw`; the original editorial crop retains its narrower image hint. Keyboard focus has a light inner ring and a dark outline for visibility on both light and dark surfaces.

The Mongo content catalog, exact CMS source scopes, content resolvers, route registry, publication rules and quote journey remain shared. Canyon has its own bounded website design identity for analytics and saved attribution. The isolated preview API admits both named designs; this does not add an experiment or change Lead eligibility. A heading accent is applied after resolving its entire CMS field, so Owner edits remain one complete value.
